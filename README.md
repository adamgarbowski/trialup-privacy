# Polityka prywatności aplikacji TrialUp

**Obowiązuje od:** 15 listopada 2026 r.
**Administrator / autor aplikacji:** Adam Garbowski
**Kontakt:** segeta.up@gmail.com

## Jakie dane zbiera aplikacja

TrialUp służy do zapisywania ocen z doświadczeń polowych. Wszystko, co wpisujesz — nazwy doświadczeń, daty, oceny,
notatki, login i hasło — jest zapisywane **wyłącznie w pamięci Twojego telefonu**.

Aplikacja:

- **nie ma dostępu do internetu** (nie prosi o to uprawnienie) i niczego nie wysyła na żaden serwer,
- nie zbiera danych o lokalizacji, kontaktach, zdjęciach ani o sposobie korzystania z telefonu,
- nie zawiera reklam ani narzędzi analitycznych,
- nie udostępnia danych autorowi aplikacji ani nikomu innemu.

Hasło jest przechowywane w telefonie w postaci skrótu kryptograficznego, nie jawnym tekstem.

## Kiedy dane opuszczają telefon

Tylko wtedy, gdy sam o tym zdecydujesz: eksportując wyniki (Excel, CSV, HTML), zapisując kopię zapasową albo wysyłając
raport błędu. Plik trafia wtedy tam, gdzie go wskażesz (np. do poczty lub na dysk). Raport błędu zawiera wersję aplikacji,
model telefonu, wersję Androida i techniczny opis błędu.

## Usuwanie danych

Dane usuwasz w aplikacji (usunięcie doświadczenia) albo odinstalowując ją — odinstalowanie kasuje wszystkie dane aplikacji
z telefonu. Kopia zapasowa Androida w chmurze jest dla tej aplikacji wyłączona.

## Dzieci

Aplikacja jest narzędziem zawodowym i nie jest przeznaczona dla dzieci.

## Zmiany

O zmianach tej polityki poinformujemy, publikując nową wersję pod tym samym adresem.

# TrialUp privacy policy (English)

**Effective from:** 15 November 2026 · **Developer:** Adam Garbowski · **Contact:** segeta.up@gmail.com

TrialUp records field-trial assessments. Everything you enter — trial names, dates, assessments, notes, login and
password — is stored **only on your phone**. The app has no internet permission and sends nothing to any server.
It collects no location, contacts, photos or usage data, contains no ads or analytics, and shares nothing with the
developer or third parties. The password is stored as a cryptographic hash.

Data leave the phone only when you choose to export results, save a backup or send an error report; the file goes
where you direct it. An error report contains the app version, phone model, Android version and a technical
description of the error.

Delete data inside the app or by uninstalling it; uninstalling removes all app data from the phone. Android cloud
backup is disabled for this app. The app is a professional tool and is not directed at children.
